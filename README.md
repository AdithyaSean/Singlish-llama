# Singlish-llama

## Description
A specialized project focused on fine-tuning LLaMA models for Singlish (Singaporean-Malaysian English) language understanding and generation. This project utilizes advanced techniques including continued pre-training and optimization using Unsloth for improved performance on Singlish text processing.

## Features
- Continued pre-training of LLaMA 3 1.8B model on Singlish datasets
- Optimization using Unsloth for improved training efficiency
- Google Colab integration for accessible training
- Comprehensive scripts for data processing and model training

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/AdithyaSean/Singlish-llama.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Singlish-llama
   ```

## Usage
The main training notebook `Llama_3_1_8B_Continued_pretraining_Singlish_+_Unsloth_+_Colab.ipynb` contains the complete pipeline for model training and fine-tuning. You can run this notebook in Google Colab for the best experience.

## Project Structure
- `/scripts` - Contains utility scripts for data processing and model training
- `/images` - Project-related images and visualizations
- `report.md` - Detailed project documentation and findings
